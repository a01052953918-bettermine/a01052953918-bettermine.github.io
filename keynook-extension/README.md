# 키눅 자동입력 확장 (프로토타입)

키눅 웹앱(`/keynook/`)에서 내보낸 백업 파일을 가져와서, 지금 보고 있는 페이지의 로그인 필드에 저장된 계정을 채워 넣는 브라우저 확장입니다.

**대리 로그인이 아닙니다.** 아이디·비밀번호 입력란을 채워 넣기만 하고, 로그인 버튼은 항상 사용자가 직접 눌러야 합니다.

## 설치 (개발자 모드)

아직 크롬 웹 스토어에 등록되지 않았습니다 — 스토어 등록은 별도의 개발자 계정과 심사 절차가 필요해서 이번 범위에는 포함하지 않았습니다. 대신 크롬 계열 브라우저(Chrome, Edge, Whale 등)에서 개발자 모드로 즉시 설치해 쓸 수 있습니다.

1. 저장소를 로컬에 클론(또는 다운로드)합니다.
2. 주소창에 `chrome://extensions` 입력
3. 우측 상단 **개발자 모드** 토글 켜기
4. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 이 저장소의 `keynook-extension/` 폴더 선택
5. 툴바에 키눅 아이콘이 생깁니다

## 사용법

1. 먼저 [키눅 웹앱](../keynook/)에서 계정을 등록하고, "백업 · 내보내기"에서 암호화 JSON 파일을 내보냅니다.
2. 확장 아이콘 클릭 → **백업 파일 가져오기**로 방금 내보낸 파일 선택
3. 마스터 비밀번호로 잠금 해제
4. 로그인하려는 사이트에서 확장 아이콘을 클릭하면, 그 사이트에 등록된 계정이 있으면 목록에 뜹니다 (URL 필드가 등록돼 있어야 매칭됩니다)
5. **채우기** 클릭 → 현재 페이지의 아이디·비밀번호 입력란이 채워집니다 → 로그인은 직접 눌러주세요

## 알아둘 점

- 웹앱과 저장소가 분리되어 있습니다(브라우저 보안 정책상 확장이 일반 웹페이지의 로컬 저장소에 접근할 수 없음). 계정을 추가·수정했다면 웹앱에서 다시 내보내고 확장에 다시 가져와야 최신 상태로 동기화됩니다.
- 팝업을 닫으면 다시 잠깁니다 — 열 때마다 마스터 비밀번호를 입력해야 합니다.
- 필드 인식은 휴리스틱(비밀번호 입력란 기준으로 가장 가까운 아이디/이메일 입력란 탐색)이라, 구조가 특이한 로그인 폼에서는 인식이 안 될 수 있습니다.
- 금융·정부 계정처럼 비밀번호를 저장하지 않은 계정은 애초에 채울 게 없어 목록에 나오지 않습니다.
- 보안 감사를 거치지 않은 프로토타입입니다.
